# --- torch is deliberately ABSENT -------------------------------------------
# Colab preinstalls torch 2.11.0, built against its own CUDA driver. Naming
# torch here makes pip re-resolve it, which at best wastes minutes on a ~2.5 GB
# wheel set and at worst installs a build that cannot see the GPU. Tutorial 3
# uses the torch Colab already shipped. The local verification venv installs
# torch==2.11.0+cpu via verify/requirements-verify.txt instead.
